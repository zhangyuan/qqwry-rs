# qqwry-rs

A Rust library and command-line tool for IPv4 address lookup using the
[纯真 (qqwry.dat)](https://github.com/metowolf/qqwry.dat) database.

## Library

```rust
use qqwry::Qqwry;

let qqwry = Qqwry::new("data/qqwry.dat")?;
let location = qqwry.lookup("8.8.8.8")?;
println!("{location}");
// 美国–加利福尼亚州–圣克拉拉–山景城, 谷歌公司DNS服务器
println!("{}, {}", location.location, location.isp);

// If you already have a parsed address, skip the string parsing:
let location = qqwry.lookup_ip("8.8.8.8".parse()?)?;
# Ok::<(), Box<dyn std::error::Error>>(())
```

`Qqwry::from_bytes` builds a database from an in-memory image, which is handy
when the file is embedded in the binary.

## Command line

```
qqwry <database> <ip>...   look up one or more addresses
qqwry <database>           read addresses from stdin, one per line
qqwry -h | --help          show this help
```

A single address prints `location, isp`; several addresses (or stdin) print
`ip, location, isp` per line.

```console
$ qqwry data/qqwry.dat 8.8.8.8
美国–加利福尼亚州–圣克拉拉–山景城, 谷歌公司DNS服务器

$ qqwry data/qqwry.dat 8.8.8.8 1.1.1.1
8.8.8.8, 美国–加利福尼亚州–圣克拉拉–山景城, 谷歌公司DNS服务器
1.1.1.1, 澳大利亚, APNIC/CloudFlare公共DNS服务器
```

## Database

The database is not checked in. Download the latest copy (~27 MB):

```console
mkdir -p data
curl -fsSL -o data/qqwry.dat \
  https://github.com/metowolf/qqwry.dat/releases/latest/download/qqwry.dat
```

## Caching

`Qqwry::new` reads the whole file into memory once, and every later lookup is
a pure in-memory operation — the database is not read per request. `Qqwry` is
`Send + Sync`, so build it once and share it:

```rust
use std::sync::{Arc, OnceLock};

use qqwry::Qqwry;

static DB: OnceLock<Arc<Qqwry>> = OnceLock::new();

let db = DB.get_or_init(|| Arc::new(Qqwry::new("data/qqwry.dat").unwrap()));
let location = db.lookup("8.8.8.8")?;
# Ok::<(), Box<dyn std::error::Error>>(())
```

Dropping the last `Arc` releases the ~27 MB, so "unload after a long idle
period" is just dropping your copy and rebuilding later. If the database is
refreshed while the process runs, watch its modification time and rebuild when
it changes. The library keeps no global state or cache of its own.

## Testing

Unit tests run against small, hand-built databases and need no data:

```console
cargo test
```

The integration tests exercise a real database and are ignored by default.
Point them at a file with `QQWRY_DB`, or place it at `data/qqwry.dat`, then:

```console
cargo test --test lookup -- --ignored
```

Without either, the tests download the database into the temporary directory.
